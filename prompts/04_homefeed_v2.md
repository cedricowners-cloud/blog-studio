# 방식 4: 홈피드 추천 v2 (감성·공감 유도)

> **Use Case**: 라이프스타일, 일상 기록, 감성 콘텐츠, 에세이
> **적합 인지단계**: L1 (공감 확산), L4 (경험 공유)
> **전략 핵심**: 네이버 홈피드 알고리즘 최적화. 체류/공유/공감 신호 극대화

---

## 프롬프트 본문 (공통 온톨로지 뒤에 이어붙이기)

```
═══════════════════════════════════════════════
[방식 4 특화 온톨로지] 홈피드 추천
═══════════════════════════════════════════════

## Class: 감성콘텐츠구조
├─ 스토리아크
│  ├─ 상황제시: 구체적 장면/시점
│  ├─ 감정전환: 기대/실망/깨달음/감사 등
│  ├─ 전환점: 어떤 사건/선택
│  └─ 현재관점: 지금 돌아보면
│
├─ 공감유도
│  ├─ 보편적 고민 터치 (일, 돈, 관계, 건강, 시간)
│  ├─ "나만 그런 줄 알았는데" 모먼트
│  └─ 독자에게 말 거는 문장
│
└─ 시각적공간감
   ├─ 문단 간 줄바꿈 적극 활용
   ├─ 짧은 문장 리듬 (긴 문장/짧은 문장 교차)
   └─ 이미지 친화적 섹션 구조

## Class: 개인스토리요소
├─ 구체성
│  ├─ 정확한 시점 ("2026년 3월 어느 화요일")
│  ├─ 감각적 디테일 (소리/냄새/온도)
│  └─ 특정 장소/인물 (익명화 가능)
│
└─ 보편성
   ├─ 개인 경험이지만 다수가 공감할 주제
   └─ 특수한 상황 속 보편적 감정

## 공리 (방식 4 특화, 공통 10개 이후 번호)
11. 개인 스토리 요소 최소 2개 포함 (구체 시점·장소·인물)
12. 감정 표현 키워드 최소 5개 이상 ("설렜다", "막막했다", "안심됐다" 등)
13. 독자에게 말 거는 문장 최소 3회 ("혹시 이런 경험 있으세요?", "공감되시나요?")
14. 이미지 삽입 태그 최소 6개 (감성 사진 위주, 짧은 텍스트 사이 배치)
15. 문단 간 줄바꿈 활용 (한 화면에 너무 많은 텍스트 금지)
16. 제목에 감성 표현 또는 질문형 포함 (예: "...해보니 느낀 것", "왜 우리는 ~할까")

※ 방식 4는 공리 3(1,500자)을 다소 완화 적용 가능 (1,200자 이상 허용)
  단, 스토리 완성도 우선.

═══════════════════════════════════════════════
[방식 4 글 구조 — 감성 스토리 아크]
═══════════════════════════════════════════════

① 상황 제시 도입부
- 구체적 시점/장소로 시작
- "저는 ~하던 날이었어요"
- 독자 호기심 유발

② 고민/딜레마 섹션
- 보편적 고민으로 연결
- 감정 표현 풍부하게
- 독자에게 질문 1~2개

③ 전환점/발견
- 어떤 계기로 달라졌는지
- 구체 사건·대화·생각

④ 해결/결과
- 실제 어떻게 되었는지
- 변화 전후 비교 (꼭 표 아니어도 됨)

⑤ 지금의 관점
- 돌아보며 느낀 것
- 독자에게 전하고 싶은 한 마디

⑥ 공감 CTA
- 댓글로 경험 공유 유도
- "여러분은 어떠세요?"

═══════════════════════════════════════════════
[출력 지시]
═══════════════════════════════════════════════

공통 출력 형식 6개 섹션 준수. 단,
§3 본문은 감성 스토리 아크 6단계 구조로 작성.
§4 공리 검증표에 공통 10개 + 방식 4 특화 6개(11~16) 전부 포함 → "N/16" 형식.
  (단, 공리 3은 1,200자 이상으로 완화 적용)
§5 개선 제안에 "공감 포인트 위치 분석" 추가.
```

## Brand Voice 적용 (v2.1)

`{author_identity}`, `{consultancy_name}` 변수가 제공된 경우, 공통 온톨로지의 [브랜드 보이스] 섹션 규칙을 이 방식의 글 구조에도 적용:

- 도입부 첫 문단에 작성자 정체성 1회 자연 노출
- 컨설팅 경험·사례 언급 시 소속명 사용
- 마무리 CTA에 정체성+소속명 조합
- 글당 각 2회 이하로 제한

변수가 비어있으면 이 섹션은 건너뛰고 일반 글로 작성.
