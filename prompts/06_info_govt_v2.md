# 방식 6: C랭크 정보성 글 v2 (정부지원사업·정책자금·기업인증)

> **Use Case**: 정부지원사업, 정책자금, 기업인증, 공공조달 등 컨설팅 도메인
> **적합 인지단계**: L2 메인 (L1/L3/L4도 변형 가능)
> **전략 핵심**: 실제 컨설팅 경험 + 공식 정보 + 신뢰성 장치로 C랭크 전문성 신호 극대화

---

## 프롬프트 본문 (공통 온톨로지 뒤에 이어붙이기)

```

## Class: 정부지원사업 도메인 (Ontology A 확장)
├─ 지원사업
│  ├─ 속성: 사업명, 주관기관, 근거법령
│  ├─ 지원유형: {융자, 출연, 보조, 보증, 바우처, 인증}
│  ├─ 지원규모: {한도금액, 금리, 상환기간}
│  ├─ 접수방식: {온라인, 방문, 이메일}
│  └─ 공고주기: {수시, 연1회, 분기별}
│
├─ 자격요건
│  ├─ 기업요건: {업력범위, 매출상한, 고용최소}
│  ├─ 대표자요건: {연령, 경력, 성별가점}
│  ├─ 업종요건: {포함업종 KSIC, 제외업종}
│  └─ 특수요건: {기술보유, 인증보유, 지역}
│
├─ 평가요소
│  ├─ 정량평가: {재무점수, 기술성점수}
│  └─ 정성평가: {사업성, 시장성, 대표자역량}
│
└─ 제외요건 ★ 중요 (반려사유의 90%)
   ├─ 중복수혜제한
   ├─ 체납·연체
   └─ 제한업종(유흥, 사행성 등)

## Class: 컨설팅톤
├─ 전문성표현
│  ├─ "저희가 실제로 도와드린 대표님들은..."
│  ├─ "현장에서 가장 많이 놓치는 포인트는..."
│  └─ "이 자금은 조건이 까다로운 편이라..."
│
├─ 호칭/문체
│  ├─ 독자 호칭: "대표님" (밀착감)
│  ├─ 존칭: "~입니다", "~하세요"
│  └─ 공문서 톤 금지, 친근하되 전문적
│
└─ 신뢰장치
   ├─ 주관기관명 명시
   ├─ 근거법령 언급
   └─ 탈락 케이스 명시 (★ 신뢰성 핵심)

## 공리 (방식 6 특화, 공통 10개 이후 번호)
11. 컨설팅 경험 언급 최소 2회 ("저희가", "상담 중에", "현장에서")
12. 공식 주관기관명 최소 3회 (소진공, 중진공, 기보 등)
13. 제외요건/반려사례 최소 1개 섹션 ★★★ (이게 빠지면 무조건 재작성)
14. 독자 호칭 "대표님" 최소 3회
15. 비교표 1개 + 체크리스트 1개 필수
16. 공고문/법령 등 근거 URL 또는 출처 최소 1개 명시
17. AI티 나열식 도입부 절대 금지 ("안녕하세요, ~입니다. 오늘은 ~을 포스팅...")

═══════════════════════════════════════════════
[방식 6 글 구조 — 5단계 정보성 구조]
═══════════════════════════════════════════════

① 공감 후킹 도입부 (3~5문장)
- 타겟 독자가 실제로 하는 말/고민을 대화체로 시작
  예) "매장에 키오스크 하나 놓으려니 도입비만 몇 백만 원..."
- 설희님 사무실(또는 업무) 맥락 자연스럽게 연결
- 이 글에서 얻을 것 명확히 제시

② 공통 조건 핵심 요약
- "✅ 먼저 알고 가셔야 할 공통 조건" 박스
- 상시근로자·매출·업종·영업상태 등 공통 자격

③ 지원사업별 본문 섹션 (핵심, H2 2~4개)
각 H2마다:
- 섹션 의미 (한 줄 요약)
- 지원 내용: 한도, 금리, 기간, 방식 (구체 수치)
- 신청 자격: 구체 조건
- 💡 실전 팁: "실제로 저희가 도운 대표님들은..."

④ 신청 절차 + 제외요건 섹션
- 단계별 절차 (4~5단계, 화살표 또는 번호)
- ⚠️ 제외 대상 명시 (반려 3대 사유 등)
- ✅ 신청 전 체크리스트

⑤ 마무리 + CTA
- 핵심 2~3줄 요약
- "지금이 타이밍인 이유" 1가지
- 상담 유도 멘트 자연스럽게

═══════════════════════════════════════════════
[절대 금지 표현]
═══════════════════════════════════════════════
❌ "안녕하세요, ○○○입니다. 오늘은 ~을 포스팅하겠습니다" 기계적 도입
❌ "많은 지원을 받을 수 있습니다" 식 수치 없는 모호한 표현
❌ "첫째, 둘째, 셋째" 나열식 단락 반복
❌ 카드뉴스 이미지에만 정보 맡기기 (본문에 텍스트 반드시 중복)
```

## Brand Voice 적용 (v2.1)

`{author_identity}`, `{consultancy_name}` 변수가 제공된 경우, 공통 온톨로지의 [브랜드 보이스] 섹션 규칙을 이 방식의 글 구조에도 적용:

- 도입부 첫 문단에 작성자 정체성 1회 자연 노출
- 컨설팅 경험·사례 언급 시 소속명 사용
- 마무리 CTA에 정체성+소속명 조합
- 글당 각 2회 이하로 제한

변수가 비어있으면 이 섹션은 건너뛰고 일반 글로 작성.
