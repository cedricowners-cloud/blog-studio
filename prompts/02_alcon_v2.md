## Class: 다중검색의도
├─ 의도분류
│  ├─ 가격비교형: "얼마인지" "최저가" "비용"
│  ├─ 방법탐색형: "어떻게" "방법" "신청법"
│  ├─ 비교결정형: "vs" "차이" "추천"
│  ├─ 후기확인형: "후기" "실사용" "리얼"
│  └─ 기초입문형: "초보" "뜻" "개념"
│
├─ 의도매핑원칙
│  ├─ 하나의 메인키워드 → 4~6개 의도 동시 커버
│  ├─ 각 의도 = 하나의 H2 섹션
│  └─ 각 섹션 독립 가독성 (어디서 들어와도 이해 가능)
│
└─ 롱테일전략
   ├─ 각 섹션마다 관련 롱테일 키워드 1~2개 배치
   └─ 서브키워드는 서로 다른 섹션에 분산

## Class: 모바일최적화
├─ 가독성
│  ├─ 한 문단 최대 2~3문장
│  ├─ 소제목 간격 여유있게
│  └─ 핵심 단어 Bold(**단어**) 강조
│
└─ 스캔가능성
   ├─ 목차 또는 핵심 요약 박스
   └─ 리스트·번호 적절히 혼용

## 공리 (방식 2 특화, 공통 10개 이후 번호)
11. H2 소제목 4~6개 = 검색의도 4~6개에 1:1 매핑
12. 각 H2 섹션 첫 문장에 해당 의도의 핵심 키워드 배치
13. 한 문단 2~3문장 이하 (모바일 가독성 강제)
14. 각 섹션마다 롱테일 키워드 1~2개 배치
15. 핵심 요약 박스 또는 목차를 본문 상단에 배치
16. Bold(**...**) 강조 최소 5회 이상 (핵심 단어 부각)

① 검색의도 먼저 분석 (추론 STEP에서 수행)
- "{메인키워드}"를 검색하는 독자의 의도 4~6개 도출
- 예: 가격확인 / 사용법 / 비교선택 / 후기확인 / 주의사항

② 핵심 요약 박스 (본문 최상단)
- "이 글에서 확인할 수 있는 것" N가지 리스트
- 독자가 빠르게 원하는 섹션으로 점프 가능

③ 의도별 H2 섹션 4~6개
각 섹션 구조:
- [H2: 의도 키워드 포함 제목]
- 섹션 도입 1~2문장 (해당 의도 공감)
- 핵심 정보 (짧은 문단 + Bold 강조)
- 관련 롱테일 키워드 자연 배치
- 필요 시 미니 표/체크리스트

④ 종합 비교 섹션 (선택적)
- 여러 선택지가 있는 경우 큰 비교표 1개

⑤ 마무리 + 다음 행동 안내
- 의도별로 서로 다른 다음 행동 2~3개 제시
- "가격이 궁금했다면 → OO 확인", "신청하시려면 → OO 준비"

## Brand Voice 적용 (v2.1)

`{author_identity}`, `{consultancy_name}` 변수가 제공된 경우, 공통 온톨로지의 [브랜드 보이스] 섹션 규칙을 이 방식의 글 구조에도 적용:

- 도입부 첫 문단에 작성자 정체성 1회 자연 노출
- 컨설팅 경험·사례 언급 시 소속명 사용
- 마무리 CTA에 정체성+소속명 조합
- 글당 각 2회 이하로 제한

변수가 비어있으면 이 섹션은 건너뛰고 일반 글로 작성.
