# 방식 5: 인사이트 엣지 v2 (통념 반박·전문가 관점)

> **Use Case**: 전문가 의견, 업계 인사이트, 트렌드 비평, 차별화된 분석
> **적합 인지단계**: L3 (경험자 관점 업그레이드), L4 (실패 경험자 재도전)
> **전략 핵심**: 기존 통념을 뒤집어 독자의 인식 전환을 유도. 전문성 기반 차별화

## Class: 통념반박구조
├─ 통념식별
│  ├─ "일반적으로 알려진 것": 다수가 믿는 내용
│  ├─ "정설로 통하는 주장": 업계/미디어의 기본 전제
│  └─ "뻔한 조언": 반복되는 조언 패턴
│
├─ 반박근거
│  ├─ 데이터/통계 (최소 3개)
│  ├─ 전문가 의견 (업계 현장 경험)
│  └─ 실제 사례 (성공/실패 케이스)
│
└─ 대안제시
   ├─ 새로운 관점 또는 접근법
   ├─ 실제 적용 가능한 구체 방법
   └─ 기존 통념을 적용했을 때의 리스크

## Class: 전문가톤
├─ 권위성
│  ├─ 경력/자격 기반 발언 (직접 언급)
│  ├─ 업계 전문용어 적절 사용
│  └─ 단정형 표현 (방식 1과 정반대)
│
└─ 균형감
   ├─ "다만..."으로 예외/조건 명시
   ├─ 본인 주장도 검증 가능한 형태로
   └─ 반대 의견 인정 후 재반박

## 공리 (방식 5 특화, 공통 10개 이후 번호)
11. 기존 통념 명시 섹션 필수 (서두에 "일반적으로는 ...라고들 합니다")
12. 통념 반박 근거 데이터/사례 최소 3개
13. 대안적 관점 또는 방법 명시 (섹션 후반)
14. 전문가 근거 언급 최소 2회 ("현장에서 보면", "컨설팅해보니")
15. 단정형 표현 비중 높임 (방식 1의 구어체와 정반대, 단 근거 기반)
16. 제목에 반박/전환 암시 포함 (예: "~는 틀렸다", "왜 ~가 안 되는가", "~의 숨겨진 진실")

① 통념 제시 도입부
- "일반적으로 ~라고 알려져 있습니다"
- "많은 전문가들이 ~를 권합니다"
- 독자가 이미 알고 있는 내용 확인

② 문제 제기
- "하지만 실제 현장에서는..."
- "제가 컨설팅하면서 본 바로는..."
- 독자의 흔들림 유발

③ 반박 근거 섹션 (H2 2~3개)
- 근거 1: 데이터/통계
- 근거 2: 실제 사례
- 근거 3: 업계 구조/제도 배경

④ 대안 제시 섹션
- 새로운 관점 또는 접근법
- "그렇다면 어떻게 해야 하는가"
- 구체 방법 또는 체크리스트

⑤ 반대 의견 고려
- "다만 이런 경우엔 기존 방식이 여전히 유효합니다"
- 균형감 확보

⑥ 결론 + 독자 행동 유도
- 핵심 주장 재강조
- 독자 상황 점검 체크리스트 또는 질문
