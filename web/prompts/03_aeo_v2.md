# 방식 3: AEO(AI 브리핑) v2 (AI 인용 최적화)

> **Use Case**: 정보성 글, 비교 가이드, "~란?"·"~의 차이" 형태
> **적합 인지단계**: L1, L2
> **전략 핵심**: 네이버 AI 요약/AI 브리핑 상단 노출 목표. AI가 이 글을 인용하기 좋은 구조로 작성

---

## 프롬프트 본문 (공통 온톨로지 뒤에 이어붙이기)

```
═══════════════════════════════════════════════
[방식 3 특화 온톨로지] AEO (Answer Engine Optimization)
═══════════════════════════════════════════════

## Class: AI인용친화구조
├─ 답변단위화
│  ├─ 질문-답변 페어 명확 분리
│  ├─ 하나의 질문 = 하나의 독립 단락
│  └─ 답변 첫 문장에 결론 명시 (역피라미드)
│
├─ 스니펫최적화
│  ├─ 핵심 요약 박스 (본문 최상단)
│  ├─ 정의·개념은 짧고 명확한 한 문장
│  └─ 숫자 기반 답변 우선 ("5가지", "3단계", "평균 50만 원")
│
└─ 구조화마크업
   ├─ H2/H3 위계 엄격
   ├─ 리스트/번호 적극 활용
   └─ 표로 가능한 내용은 표로

## Class: FAQ구조
├─ 질문선정
│  ├─ "~란?" (정의형)
│  ├─ "~가 뭐가 좋은가?" (혜택형)
│  ├─ "~는 누가 받을 수 있나?" (자격형)
│  ├─ "~는 어떻게 신청하나?" (절차형)
│  └─ "~의 단점/주의할 점은?" (리스크형)
│
└─ 답변형식
   ├─ 결론 먼저 (첫 1문장)
   ├─ 근거/설명 다음 (2~3문장)
   └─ 구체 예시 마지막 (1문장)

## 공리 (방식 3 특화, 공통 10개 이후 번호)
11. 본문 최상단에 핵심 요약 박스 (3~5줄) 배치
12. FAQ 섹션 필수 (최소 5개 질문-답변 페어)
13. 각 FAQ 답변 첫 문장에 결론 명시 (역피라미드 구조)
14. 숫자/수치 기반 답변 비율 50% 이상
15. 정의·개념 설명은 한 문장으로 간결하게
16. 표 또는 구조화 리스트 2개 이상

═══════════════════════════════════════════════
[방식 3 글 구조 — AEO 최적화]
═══════════════════════════════════════════════

① 핵심 요약 박스 (본문 최상단)
```
📌 이 글의 핵심 요약
- 주제: {주제} 한 줄 정의
- 주요 수혜 대상: ...
- 한도/규모: ...
- 신청 기한: ...
- 주의사항: ...
```

② 개념/정의 섹션 (H2: "~란? / ~의 뜻")
- 첫 문장: "{메인키워드}는 ...입니다" (한 문장 정의)
- 설명 2~3문장
- 관련 용어 미니 용어집 (표 형태)

③ 주요 내용 섹션 (H2 2~3개)
- 각 H2마다 하위 H3 2~3개
- H3 제목은 사용자 질문 형태로 ("얼마까지 받을 수 있나요?")
- 답변은 역피라미드 (결론 → 근거 → 예시)

④ 비교/선택 섹션 (선택적 H2)
- 여러 옵션이 있다면 큰 비교표 1개

⑤ FAQ 섹션 (필수 H2)
- 최소 5개 질문-답변
- 독자가 실제 검색할 만한 형태의 질문
- 각 답변은 50~150자 내외 (AI 요약에 인용되기 적절한 길이)

⑥ 마무리 + 추가 정보 안내
- 관련 글 링크 또는 공식 출처 안내

═══════════════════════════════════════════════
[출력 지시]
═══════════════════════════════════════════════

공통 출력 형식 6개 섹션 준수. 단,
§3 본문에 반드시 핵심 요약 박스(최상단) + FAQ 섹션(최소 5개)을 포함할 것.
§4 공리 검증표에 공통 10개 + 방식 3 특화 6개(11~16) 전부 포함 → "N/16" 형식.
§5 개선 제안에 "AI 브리핑 인용 가능성 분석" 1줄 추가.
```

## Brand Voice 적용 (v2.1)

`{author_identity}`, `{consultancy_name}` 변수가 제공된 경우, 공통 온톨로지의 [브랜드 보이스] 섹션 규칙을 이 방식의 글 구조에도 적용:

- 도입부 첫 문단에 작성자 정체성 1회 자연 노출
- 컨설팅 경험·사례 언급 시 소속명 사용
- 마무리 CTA에 정체성+소속명 조합
- 글당 각 2회 이하로 제한

변수가 비어있으면 이 섹션은 건너뛰고 일반 글로 작성.
