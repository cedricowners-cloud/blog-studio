## 인지단계별 대표고민·구매동인

### L1 (정책자금이라는 게 있는 줄도 모름)

```
대표고민:
- 운영자금이 부족한데 어디서 빌려야 할지 모르겠다
- 시중은행 대출 이자가 너무 부담된다
- 정부에서 사업하는 사람한테 뭐 해주는 게 있다는데 잘 모른다

구매동인:
- 시중은행보다 훨씬 저금리/장기상환이 가능하다는 정보 첫 노출
```

### L2 (있는 건 아는데 본인 대상인지 모름)

```
대표고민:
- 자격요건이 복잡해서 내가 해당되는지 헷갈린다
- 업력·매출·고용 등 어디서부터 따져봐야 할지 모르겠다
- 신청 준비 시간 들였다가 자격 미달이면 시간 낭비
- 지원사업이 너무 많아서 어떤 게 우리 회사에 맞는지 모르겠다

구매동인:
- 자가진단 체크리스트로 본인 자격 즉시 확인 가능
- 자기 회사 케이스와 비슷한 실제 승인 사례 발견
```

### L3 (대상인 건 아는데 어떻게 해야 할지 모름)

```
대표고민:
- 신청 절차가 복잡해서 어디서부터 시작할지 모르겠다
- 사업계획서·재무서류 준비가 막막하다
- 평가에서 어떤 항목을 잘 써야 점수를 받는지 모르겠다
- 컨설팅 받자니 비용이 부담스럽고 직접 하자니 자신 없다

구매동인:
- 단계별 가이드 + 실패하지 않는 작성 팁
- 평가관 관점에서 본 핵심 포인트
- 직접 vs 위임 판단 기준
```

### L4 (해봤는데 실패·반려 경험)

```
대표고민:
- 왜 반려됐는지 정확한 이유를 모르겠다 (통보서가 모호함)
- 같은 사업 재신청이 가능한지 모르겠다
- 다른 비슷한 사업으로 갈아탈 수 있는지 알고 싶다
- 다음엔 어떻게 보완해야 할지 막막하다

구매동인:
- 실제 반려 케이스 분석 + 재도전 전략
- "이런 케이스는 사실 ○○ 사업이 더 맞습니다" 같은 대안 제시
```

## 검색의도별 키워드 패턴

| 검색의도 | 키워드 패턴 예시 |
|---|---|
| **정보탐색** | "혁신성장촉진자금 뭐", "소상공인 정책자금 종류", "중기부 지원사업 목록" |
| **자격진단** | "혁신성장촉진자금 자격", "청년창업자금 신청 가능", "소진공 자금 대상" |
| **절차해결** | "정책자금 신청 방법", "기보 보증 절차", "혁신성장 신청서류" |
| **문제해결** | "정책자금 반려 사유", "자금 신청 떨어졌을 때", "재신청 방법" |
| **비교선택** | "혁신성장 vs 일반자금", "융자 vs 보조금 차이", "기보 신보 차이" |

## JTBD별 가치명제 매핑

| JTBD | 글이 제공해야 하는 핵심 가치 (이 도메인 기준) |
|---|---|
| **시간절약** | 자가진단 체크리스트로 자격 여부를 30초 안에 판단 |
| **리스크회피** | 반려 3대 사유 명시 + 본인 케이스 매칭 → 시간·비용 낭비 차단 |
| **의사결정지원** | 비교표로 비슷한 사업 중 본인에게 맞는 것 선택 |
| **자기효능감** | 단계별 신청 가이드 + 사업계획서 핵심 포인트 → 직접 진행 자신감 |
| **위임판단** | 직접 신청 vs 컨설팅 위임 비용·시간·성공률 비교 |

## 작성 가이드

- 위 대표고민은 *초안*. 사용자(설희)의 실제 클라이언트 DM/상담 기록 기반으로 정량 보강 필요.
- 검색의도별 키워드는 네이버 검색광고 API 로 정기 갱신.
- JTBD 가치명제는 글마다 다를 수 있으나 위 *기본 매핑* 이 도메인 일관성을 유지.
