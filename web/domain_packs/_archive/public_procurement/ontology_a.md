# Ontology A — 공공조달·정책자금 도메인 구조

> 정부지원사업·정책자금·기업인증·공공조달 도메인의 클래스·속성·관계·제외요건 정의.
> 출처: `prompts/06_info_govt_v2.md` 의 [방식 6 특화 온톨로지] 섹션을 도메인 분리 형태로 재정리.

---

## Class: 지원사업

```
├─ 속성(Property)
│  ├─ 사업명, 주관기관, 근거법령
│  ├─ 사업유형: {정책자금, 보조금, 바우처, 인증, 공공조달}
│  ├─ 지원유형: {융자, 출연, 보조, 보증, 바우처, 인증}
│  ├─ 지원규모: {한도금액, 금리, 상환기간}
│  ├─ 접수방식: {온라인, 방문, 이메일}
│  └─ 공고주기: {수시, 연1회, 분기별, 분기별 마감}
```

## Class: 자격요건

```
├─ 기업요건
│  ├─ 업력범위: {예비창업, 1년 미만, 1~3년, 3년 이상, 7년 이상}
│  ├─ 매출상한: {일반기준, 우대기준}
│  └─ 고용최소: {1인 이상, 5인 이상, 10인 이상}
│
├─ 대표자요건
│  ├─ 연령: {청년(만 39세 이하), 일반, 장년}
│  ├─ 경력: {동종업종 N년}
│  └─ 우대조건: {여성, 장애인, 보훈가족, 다자녀}
│
├─ 업종요건
│  ├─ 포함업종 KSIC: {제조·정보통신·서비스·제외업종 외}
│  └─ 제외업종: {유흥·사행성·부동산임대 등}
│
└─ 특수요건
   ├─ 기술보유: {특허·실용신안·디자인}
   ├─ 인증보유: {벤처·이노비즈·메인비즈·녹색}
   └─ 지역: {수도권 외, 비수도권 우대}
```

## Class: 평가요소

```
├─ 정량평가
│  ├─ 재무점수: {부채비율, 자기자본비율, 매출증가율}
│  ├─ 기술성점수: {특허·인증 보유, 기술 등급}
│  └─ 신용평가: {신용등급, 연체이력}
│
└─ 정성평가
   ├─ 사업성: {시장규모, 차별성, 실현가능성}
   ├─ 시장성: {타겟고객, 진입장벽, 경쟁우위}
   └─ 대표자역량: {경력, 책임감, 추진력}
```

## Class: 제외요건 ★ 중요 (반려사유의 90%)

```
├─ 중복수혜제한
│  ├─ 동일사업 N년 내 재신청 불가
│  └─ 유사사업 동시 신청 불가
│
├─ 체납·연체
│  ├─ 국세·지방세 체납
│  ├─ 4대보험 체납
│  └─ 금융기관 연체
│
├─ 제한업종
│  ├─ 유흥·사행성 (룸살롱·노래방·게임장 등)
│  ├─ 부동산임대업
│  └─ 비영리·종교
│
└─ 결격사유
   ├─ 회생·파산 진행 중
   └─ 영업정지·취소 이력
```

## Class: 컨설팅톤

> 글 작성 시 LLM이 일관되게 유지해야 할 톤·표현 규칙 (Brand Voice와 별개).

```
├─ 전문성표현
│  ├─ "저희가 실제로 도와드린 대표님들은..."
│  ├─ "현장에서 가장 많이 놓치는 포인트는..."
│  └─ "이 자금은 조건이 까다로운 편이라..."
│
├─ 호칭/문체
│  ├─ 독자 호칭: "대표님" (밀착감)
│  ├─ 존칭: "~입니다", "~하세요"
│  └─ 공문서 톤 금지, 친근하되 전문적
│
└─ 신뢰장치
   ├─ 주관기관명 명시 (소진공·중진공·기보 등)
   ├─ 근거법령 언급
   └─ 탈락 케이스 명시 (★ 신뢰성 핵심)
```

## Relation: 도메인 관계 그래프

- 지원사업 --주관--> 주관기관 (소진공·중진공·기보·신보 등)
- 지원사업 --근거--> 근거법령 (소상공인기본법·중소기업진흥법 등)
- 자격요건 --판정--> 대상자/비대상자
- 평가요소 --결정--> 승인/반려
- 제외요건 --차단--> 신청 자체 불가
- 신청자 --제출--> 신청서 + 사업계획서 + 첨부서류
- 주관기관 --심사--> 정량 + 정성 평가 → 결과 통보
- 결과 --통보--> 승인(자금 집행) / 반려(사유 통보)

## 작성 가이드

- 새 사업·제도 추가 시 위 4개 Class 의 속성·서브클래스에 항목 추가
- 제외요건은 **반드시 별도 Class** 로 유지 (반려사유 90% 차지)
- 신뢰장치(주관기관·근거법령) 는 글 안에서 명시적으로 언급되어야 함 (공리 #12, #13 검증 대상)
