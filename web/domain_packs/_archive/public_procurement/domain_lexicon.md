# Domain Lexicon — 공공조달·정책자금

> 정부지원사업·정책자금 도메인의 어휘집.
> LLM 글 작성 시 일관된 용어 사용을 가이드.

---

## 전문 용어 정의

| 용어 | 정의 | 일반인 표현 |
|---|---|---|
| 정책자금 | 정부·공공기관이 정책 목적으로 운용하는 융자/보조금 통칭 | 정부에서 빌려주거나 주는 사업자금 |
| 융자 | 갚아야 하는 자금 (저금리 장기상환) | 빌려주는 자금 |
| 출연·보조 | 갚지 않아도 되는 지원금 | 공짜로 주는 자금 |
| 바우처 | 특정 용도로 사용 가능한 지정 결제권 | 정부가 주는 사용권 |
| 보증 | 신보·기보가 대출 보증 → 시중은행에서 대출 가능 | 정부가 보증 서주는 것 |
| 소진공 | 소상공인시장진흥공단 | 소상공인 지원 기관 |
| 중진공 | 중소벤처기업진흥공단 | 중소기업 지원 기관 |
| 기보 | 기술보증기금 | 기술 기반 보증 기관 |
| 신보 | 신용보증기금 | 신용 기반 보증 기관 |
| KSIC | 한국표준산업분류 | 업종 분류 코드 |
| 정량평가 | 재무·기술 등 숫자로 측정 | 점수표로 매기는 평가 |
| 정성평가 | 사업성·시장성·대표역량 등 의견 평가 | 심사위원 주관 평가 |
| 제외요건 | 신청 자체가 불가능한 결격사유 | 처음부터 안 되는 조건 |
| 중복수혜제한 | 동일·유사 사업 동시 또는 일정 기간 내 재신청 불가 | 같은 자금 또 못 받음 |

---

## 자주 혼동되는 용어

- **융자 vs 보조금**: 융자는 갚아야 하지만 금리·기간이 시중보다 유리. 보조금은 안 갚아도 되지만 자격이 더 까다로움.
- **소진공 vs 중진공**: 소진공은 *소상공인*(상시근로자 5~10인 미만), 중진공은 *중소기업*(상시근로자 10인 이상~). 매출·고용 기준 다름.
- **보증 vs 융자**: 보증(신보·기보)은 정부가 *대출 보증*만 → 실제 대출은 시중은행. 융자(소진공·중진공)는 정부 기관이 *직접* 자금 지급.
- **자격요건 vs 제외요건**: 자격은 *충족해야 하는* 조건, 제외는 *해당하면 안 되는* 결격사유. 제외 1개라도 걸리면 자동 반려.

## 사용 금지 표현

- **"100% 보장"**: 모든 정책자금은 심사 결과에 따라 결과가 달라짐 — 단정 표현 법적 리스크
- **"무조건 승인"**: 동일 — 사실 왜곡
- **"꿀팁"**: 신뢰 톤을 훼손, 컨설팅 전문성과 부합 안 함
- **"안녕하세요, 오늘은 ~를 포스팅하겠습니다"**: AI티 도입부, SEO 신호 약화 (방식 6 공리 #17)
- **"많은 지원을 받을 수 있습니다"**: 수치 없는 모호한 표현, 신뢰 약화

## 권장 표현

- **자격 충족 가능성 표현**: "충족 가능성이 높습니다" (단정 X, 조건부 O)
- **반려 가능성 경고**: "이 조건이 있으면 신청 자체가 어려울 수 있습니다"
- **컨설팅 경험 인용**: "저희가 실제로 도와드린 대표님들은...", "현장에서 가장 많이 놓치는 포인트는..."
- **출처 명시**: "(소진공 2025년 1월 공고 기준)" 같은 시점·출처 명시
- **독자 호칭**: "대표님" (밀착감, 컨설팅톤)
- **수치 표기**: "한도 7천만 원, 금리 2.0%~3.0%" (구체값 + 범위 함께)

## 작성 가이드

- 새 사업 추가 시 *사업명 약어 ↔ 정식명* 매핑 추가 (예: 혁신성장촉진자금)
- 사용자가 글 검수 중 어색한 표현 발견 시 *사용 금지* 또는 *권장 표현* 섹션에 즉시 반영
- 일반인 표현 칸은 SEO 키워드와 매칭되도록 유지 (검색 의도 맞추기)
