# Ontology B Values — &lt;도메인명&gt; 독자 인스턴스

> 독자 다층 모델(Ontology B v2)의 **값**을 채워 넣는다.
> 골격(축: 인지단계 / 검색의도 / JTBD)은 공통, 각 축의 *구체값*만 도메인별.

---

## 인지단계별 대표고민·구매동인

### L1 (존재 자체를 모름)

```
대표고민:
- <이 도메인 자체를 모르는 사람의 고민>
- <고민2>
- <고민3>

구매동인:
- <이 단계에서 알게 됐을 때 행동을 시작하게 하는 트리거>
```

### L2 (있는 건 아는데 본인 대상인지 모름)

```
대표고민:
- <자격 요건 헷갈림>
- <시간·비용 부담 우려>

구매동인:
- <자가진단 가능한 정보를 원함>
```

### L3 (대상인 건 아는데 절차를 모름)

```
대표고민:
- <어디서부터 시작할지 모름>
- <서류·절차 복잡함>

구매동인:
- <단계별 가이드를 원함>
```

### L4 (해봤는데 실패·반려 경험)

```
대표고민:
- <왜 실패했는지 모름>
- <재도전이 두려움>

구매동인:
- <실패 원인 분석 + 재도전 전략>
```

## 검색의도별 키워드 패턴

| 검색의도 | 키워드 패턴 예시 |
|---|---|
| **정보탐색** | "&lt;도메인&gt; 뭔지", "&lt;개념&gt; 정의" |
| **자격진단** | "&lt;사업명&gt; 자격", "&lt;X&gt; 가능한지" |
| **절차해결** | "&lt;X&gt; 신청 방법", "&lt;Y&gt; 절차" |
| **문제해결** | "&lt;X&gt; 반려", "&lt;Y&gt; 실패", "&lt;Z&gt; 안 될 때" |
| **비교선택** | "&lt;A&gt; vs &lt;B&gt;", "&lt;A&gt; 차이" |

## JTBD별 가치명제 매핑

| JTBD | 글이 제공해야 하는 핵심 가치 (이 도메인 기준) |
|---|---|
| **시간절약** | &lt;이 도메인에서 "시간을 아낀다"는 것의 구체값&gt; |
| **리스크회피** | &lt;실수·실패를 막는 구체값&gt; |
| **의사결정지원** | &lt;선택을 명확히 하는 구체값&gt; |
| **자기효능감** | &lt;직접 해낼 수 있다는 자신감의 구체값&gt; |
| **위임판단** | &lt;전문가에게 맡길지 결정하는 기준&gt; |

## 작성 가이드

- 각 단계당 대표고민 3~5개 (실제 클라이언트 인터뷰·DM·댓글에서 추출)
- 구매동인 1~2개 (단계 진입을 결정하는 트리거)
- 키워드 패턴은 실제 검색 데이터 기반 (네이버 검색광고 API)
- JTBD 가치명제는 추상적 단어 대신 *구체값*
