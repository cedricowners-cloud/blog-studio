# Ontology A — &lt;도메인명&gt; 도메인 구조

> 도메인 자체의 클래스·속성·관계·제외요건을 정의한다.
> 이 파일은 **템플릿(빈 양식)** 이다. 도메인 패키지 작성 시 `<...>` 부분을 채워 넣음.

---

## Class: &lt;핵심개념1&gt;

```
├─ 속성(Property)
│  ├─ <속성1>, <속성2>, <속성3>, ...
│  └─ <분류값>: {값1, 값2, 값3}
│
├─ <SubClass1>
│  ├─ <속성>: ...
│  └─ ...
│
└─ <SubClass2> ★중요표시
   ├─ <속성>: ...
   └─ ...
```

## Class: &lt;핵심개념2&gt;

```
├─ 속성(Property)
│  └─ ...
└─ ...
```

---

## Relation: &lt;도메인명&gt; 관계 그래프

- &lt;개념A&gt; --&lt;관계&gt;--&gt; &lt;개념B&gt; (조건)
- ...
- 최소 5개 명시

---

## 제외요건 / 예외 케이스 (★ 중요)

```
├─ <케이스1>
│  └─ <설명>
└─ <케이스2>
   └─ <설명>
```

---

## 작성 가이드

- 핵심 클래스 5~10개
- 각 클래스의 속성 5개 이상
- 제외요건·예외 케이스는 별도 SubClass로 분리
- 클래스 간 관계 최소 5개 명시
- 도메인 특화 용어는 그대로 유지 (한국어 OK)
