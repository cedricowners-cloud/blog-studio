## 1. 무엇을 만드나

크롬 확장 프로그램 하나로 네 가지를 한다.

1. **글쓰기**: 주제를 넣으면 내 AI 키로 글을 만든다.
2. **내 말투**: 내가 쓴 글을 분석해서 같은 말투로 쓰게 한다.
3. **발행**: 네이버 글쓰기 화면에 글과 이미지를 버튼 하나로 채운다.
4. **쌓아 두기**: 주제를 여러 개 넣어 두면 자리를 비운 동안 글을 만들어 둔다.

발행과 예약 버튼은 사람이 직접 누른다.

## 2. 왜 바꾸나

| 지금 불편한 점 | 바뀐 뒤 |
|---|---|
| 발행하려면 파이썬 프로그램을 따로 띄워야 한다 | 확장 프로그램만 설치하면 된다 |
| 글 1건을 올리는 데 15분이 걸린다 | 몇 초 만에 채워진다 |
| 이미지와 표가 빠진 채 올라간다 | 자리에 맞춰 들어간다 |
| 가족이 설치하기 어렵다 | 맥과 윈도우 모두 같은 방법으로 설치한다 |
| AI 키가 서버에 저장된다 | 내 컴퓨터에만 저장된다 |

기존 blog_studio 웹은 그대로 쓴다. 키워드 조사, 순위 추적, 통계는 웹에 남는다. 8단계 SEO 글쓰기는 웹에서도, 확장에서도 쓴다.

## 3. 쓰는 모습

1. 확장에서 주제, 독자 상황, 한줄 메모를 적는다. 자세히 정하고 싶으면 글쓰기 방식과 키워드도 고른다.
2. 참고할 공고나 안내 페이지가 있으면 열어 두고 [이 탭을 자료로 추가]를 누른다.
3. [글 만들기]를 누르고 검수 카드를 본다. "확인필요" 표시가 있으면 하나씩 답한다.
4. 네이버 글쓰기 화면을 열고 [채우기]를 누른다.
5. 눈으로 확인한 뒤, 발행 창에서 태그와 발행 시간(지금 또는 예약)을 정해 직접 발행한다.

웹에서 공들여 쓴 글은 [확장으로 보내기]를 눌러 4번부터 진행한다.

## 4. 화면

| 탭 | 하는 일 |
|---|---|
| 글쓰기 | 간단 입력(주제, 독자 상황, 한줄 메모), 자료 추가, 글 만들기, 검수 카드, 글감 대기열 |
| SEO 8단계 | 키워드 하나로 시작해 프롬프트 8개를 차례로 돌린다. 한 단계씩 보면서 하거나, 한 번에 끝까지 돌리거나, 프롬프트를 복사해 직접 진행한다 |
| 발행 | 발행 대기 글 목록, 채우기, 이어 하기, 태그 복사 |
| 내 말투 | 내 글 모으기, 말투 카드, 다음 글에도 적용할 "내 규칙" |
| 설정 | AI 키 넣기와 발급 안내, 사용량, 대기열과 자동 임시저장 설정 |

처음 켜면 세 단계로 안내한다: 로그인 → AI 키 넣기 → 시험 글 채워 보기.

## 5. 지키는 원칙

1. **공개 발행은 사람이 한다.** 확장은 채우기까지만 한다. 선택 기능을 켜면 임시저장까지 한다. 발행 버튼은 어떤 경우에도 누르지 않는다.
2. **AI 키는 내 컴퓨터에만 둔다.** 서버에서 글을 만들게 하고 싶은 사람만 서버에 둔다.
3. **프롬프트는 확장에 넣지 않는다.** 확장 파일에 넣으면 설치한 사람 누구나 볼 수 있다. 로그인한 사람만 서버에서 받아 쓴다.
4. **우선순위는 사실 > 글 구조 > 내 규칙 > 말투다.** 말투 때문에 숫자나 구조가 바뀌면 안 된다.
5. **경험담은 실제 사례를 입력했을 때만 쓴다.** 입력이 없으면 AI가 지어내지 않게 한다.
6. **확인하지 못한 숫자에는 "확인필요" 표시를 단다.** 표시가 남아 있으면 채우지 않는다.
7. **네이버 에디터의 모양은 추측하지 않는다.** 손으로 만든 견본 글을 읽어서 그대로 본뜬다.

## 6. 글쓰기를 돕는 기능

| 기능 | 내용 |
|---|---|
| 간단 모드 | 주제, 독자 상황, 한줄 메모만 적는다. 글쓰기 방식과 키워드는 자동으로 정하고, 고칠 수 있다 |
| 확인필요 표시 | AI가 확인하지 못한 숫자, 날짜, 경험에 표시를 단다. 사람이 값을 넣거나 문장을 지운다 |
| 검수 카드 | 글자 수, 제목 길이, 키워드 횟수, 어긴 규칙, 확인필요 목록을 글마다 보여 준다. 숫자는 코드가 센다 |
| 내 규칙 | "글자 수는 1,500자 안팎"처럼 계속 지킬 규칙을 저장한다. 글을 고친 뒤 [이 수정을 다음 글에도 적용]을 누르면 더해진다 |
| 디자인 설정 | 인용구 6종과 구분선 8종 중 용도별로 쓸 모양을 정한다. 글마다 모양이 달라지지 않게 한다 |
| 색 강조 | 긍정 강조는 내 브랜드 색, 부정 강조는 빨강, 형광펜은 배경색으로 넣는다. 글에는 뜻만 표시하고 색은 설정에서 정한다 (만들었고 실제 화면에서 확인함) |

## 7. 자리를 비운 동안 글 쌓아 두기

**글감 대기열**
1. 주제를 여러 개 넣어 둔다. 확장에서 넣거나, 폰으로 웹에서 넣는다.
2. 글이 차례로 만들어져 "발행 대기"에 쌓인다. 검수 카드와 확인필요 표시도 같이 만들어진다.
3. 돌아와서 한 편씩 확인하고 발행하거나 예약한다.

글을 만드는 곳은 사람마다 고른다.

| | 확장에서 만들기 | 서버에서 만들기 |
|---|---|---|
| AI 키 | 내 컴퓨터에만 있다 | 서버에 저장해야 한다 |
| 조건 | 컴퓨터와 크롬이 켜져 있어야 한다 | 컴퓨터가 꺼져 있어도 된다 |
| 맞는 사람 | 키를 서버에 두고 싶지 않은 사람 | 출근해서 폰으로 주제만 넣고 싶은 사람 |

- 하루에 만드는 글 수에 상한을 둔다.
- 최근 글과 주제가 겹치면 만들지 않고 알려 준다.

**자동 임시저장 (선택 기능, 기본은 꺼짐)**
- 켜 두면 준비된 글을 네이버 임시저장함까지 넣어 둔다. 공개 발행은 하지 않는다.
- 켤 때 주의할 점을 안내하고 동의를 받는다. 하루 상한은 기본 2건이다.
- 확인필요 표시가 남은 글은 건너뛴다.
- 로그인이 풀렸거나, "작성 중인 글" 팝업이 떴거나, 채운 내용이 원본과 다르면 멈추고 알린다.
- 컴퓨터와 크롬이 켜져 있고 네이버에 로그인돼 있어야 한다.
- 채우기가 몇 초라서 이 기능 없이도 불편은 크지 않다. 임시저장함에서 바로 보고 싶은 사람을 위한 기능이다.

## 8. 이미지

- 글에는 이미 이미지 자리가 표시돼 있다. 자리마다 이미지를 정해 두면 확장이 넣는다.
- 넣을 수 있는 이미지: 카드 이미지, 무료 사진, AI 생성 이미지, 내 사진
- 블로그용 카드는 지금 있는 카드 기능에 크기 설정(썸네일, 본문용)을 더해서 만든다.
- 카드 속 숫자는 본문과 같은지 코드로 확인한다.
- 이미지를 넣다가 실패하면 이미지 단계만 다시 한다. 글을 다시 만들지 않는다.

## 9. AI 키 안내

- Gemini, OpenAI, Claude마다 카드를 둔다: 발급 페이지 열기 → 3단계 안내 → 붙여넣기 → 확인
- 안내에 넣을 내용:
  - Gemini는 무료 사용 한도가 있어서 처음 쓰기 좋다.
  - OpenAI와 Claude는 결제 수단 등록이나 충전이 필요하다.
  - ChatGPT·Claude 유료 구독과 API 요금은 별개다.
  - 각 사이트에서 월 사용 한도를 걸어 둔다.

## 10. 내 말투

1. 내 블로그 글 10~20편을 모은다. AI를 쓰기 전에 직접 쓴 글이어야 한다.
2. 분석해서 말투 카드를 만든다: 문장 끝맺음, 자주 쓰는 표현, 시작과 끝 방식, 문장 길이
3. 카드는 직접 고칠 수 있다. 정보글용, 일상글용처럼 여러 장을 둘 수 있다.
4. 글을 만든 뒤 말투가 얼마나 맞는지 보여 주고, 어긋나면 말투만 다듬는다.

## 12. 조심할 점

- **네이버가 에디터를 바꾸면 채우기가 고장 날 수 있다.** 그때를 대비해 [복사하기]를 같이 만든다.
- **로그인한 사람은 프롬프트를 볼 수 있다.** 가입을 초대한 사람만 되게 바꿔야 한다.
- **글을 만드는 중에 확장 창을 닫으면 중단된다.** 대기열도 확장에서 돌릴 때는 창이 열려 있어야 한다.
- **예시 글의 내용이 새 글에 섞일 수 있다.** 말투만 참고하게 하고 숫자는 따로 검사한다.
- **많이 올리면 계정에 문제가 생길 수 있다.** 본인 계정으로 하루 1~2건 정도만 올린다.
- **자동 임시저장은 사람 없이 네이버 화면을 조작한다.** 계정에 부담이 될 수 있어서 기본은 꺼 둔다.
- **대기열은 AI 비용을 쓴다.** 하루 상한을 넘지 않게 한다.
- **PC 크롬에서만 된다.** 휴대폰에서는 주제를 넣는 것까지만 된다.

## 13. 하지 않는 것

- 확장이 발행 버튼을 대신 누르는 일
- 사람 없이 공개로 발행하는 일
- 서로이웃·좋아요·댓글 자동화
- 다른 사람 블로그의 말투를 본뜨는 일
- 인터넷 이미지를 가져다 쓰는 일

## 14. 정해야 할 것

1. 소제목 모양: 지금처럼 큰 굵은 글씨로 할지, 인용구 모양으로 바꿀지
2. 블로그 본문 카드의 가로세로 비율
3. 네이버 예약 발행을 몇 개까지, 며칠 뒤까지 걸 수 있는지
4. 가족에게 어떻게 나눠 줄지: 직접 설치, 또는 웹스토어에 "링크를 아는 사람만"
5. 네이버 "내 템플릿"을 쓰는지
6. 가입을 초대제로 바꿀지
7. 가족의 기본 AI를 Gemini로 할지
8. 웹에서 쓰는 AI 키를 서버에 계속 둘지
9. 확장이 안정되면 기존 발행 프로그램을 숨길지
10. 네이버 글쓰기 화면에 'AI 활용 설정'이 있는지, 있으면 언제 체크해야 하는지
11. 대기열이 하루에 만드는 글 수의 기본값
12. 서버에서 만들기를 본인만 쓸지, 가족도 고를 수 있게 할지
13. 네이버 임시저장함에 글이 몇 개까지 들어가는지

## 15. 나중에 할 것

- 자료에서 사실만 뽑아 그 사실에 묶어서 쓰기
- 본문의 숫자가 자료에 있는지 코드로 대조하기
- 최신 자료를 출처 여러 개로 찾아 정리하기
- 공고 마감이나 법 개정 뒤 "수정 필요" 표시
- 발행 창에 예약 시간과 태그 미리 채우기
- 뉴스 해설 글, 체험단 후기 글
- 카드뉴스 만들기 프로그램과 연결
